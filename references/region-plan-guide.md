# Region Plan 编写指南

region plan 是本 skill 的核心方法论：把"讲稿的每一句"映射到"图上的绘制区域和时间窗"。

## 坐标系统

- box 是 `[ymin, xmin, ymax, xmax]`，归一化 0–1000，原点左上
- 换算：`像素 x = xmin/1000 * 图宽`，`像素 y = ymin/1000 * 图高`
- 一个 region 可以给 box 数组：`"box": [[...],[...]]` —— 多块区域在同一窗口同时绘制
- 也兼容 `{ymin,xmin,ymax,xmax}` 命名字典和 Gemini 风格 `box_2d`

## 三种音画对齐档位

| 档 | 条件 | 行为 |
|---|---|---|
| 精确档 | region 有 `start`/`end`（build_narration 生成） | 帧级"讲到哪画到哪" |
| 估算档 | region 只有 `annotation` | 字符数 70% + 面积 30% 分配窗口 |
| 均分档 | 没有 regions | 前 70% 时长均摊画完 |

推荐始终走精确档（build_narration 自动完成）。

## 归属判定（引擎行为，写 plan 前必读）

引擎对图上每个连通组件按三步分配到 box：

1. **中心包含**：组件中心落在 box 内 → 最小的 box 赢
2. **≥25% 覆盖**：box 罩住组件 bbox ≥25% → 覆盖率最高的赢
3. **最近中心**：距离限制内的最近 box

另外有一个 spanning 判定优先于上述一切：**组件 bbox 与 ≥2 个窗口的 box 交叠都 ≥60%（按 box 面积算）→ 归入最早的那个窗口**。

由此推出四条纪律：

### 纪律 1：box 紧贴内容，不贪宽
宽横条 box（如 `[30, 90, 125, 910]`）会和远处的大组件 bbox 相交，把大组件"拉进"最早窗口。标题 box 只罩标题文字的实际宽度。

### 纪律 2：先画窗口的 box 不要伸进后画元素的领地
比如月球区域 box 若和本影 box 同时罩住"月球+本影"组件，组件会被 spanning 拉回最早的窗口。

### 纪律 3：物理相连 = 永远一起画
连通域不可分割。想让两个元素分开讲：
- 绘图时在它们之间留 **≥8px 白缝**（锥形/三角形缝隙在尖端会收敛，尖端附近要 ≥20px）
- 用白色多边形"挖缝"是标准手法（见 eclipse.py 的 s03）
- **文字标签必须落在纯白区**——压在色块上的标签与色块连成一体

### 纪律 4：大色块先画，标签后写
AI 生图的大色块经常连成一片。构图时让主要元素彼此留白；标签文字由 make_text_layer 叠加时也遵守纪律 3。

## 半影案例（eclipse-solar s03）

本影锥物理上位于半影内部，想分开讲必须挖缝：

1. 画半影多边形（浅灰）
2. 画白色三角形挖缝：顶点超过本影锥尖 30px，上下边比锥边宽 30px——**缝太窄会在锥尖收敛处失效**（本影描边线宽 5px 会桥接到半影）
3. 重画本影锥（深色）+ 本影描边
4. 月球画在最后，与半影内缘保持 10px 白缝

即使如此，半影的整体 bbox 仍与本影 box 大量交叠 → 半影被判 spanning 归入本影窗口。**这是可接受的**：说"本影"时影子系统整体出现，说"半影"时半影标签写出。若必须彻底分离，把半影在锥尖右侧垂直切成两块独立多边形。
